# Outcome-driven Experiment

Use this Skill for a request that asks what action to take and how to know whether it
worked. Recall current user facts plus prior decisions/outcomes, obtain the relevant
metric evidence, and produce one controlled experiment. The structured decision must
name the target metric, observation window and success threshold.

Never mark a recommendation successful before a linked outcome is observed. State
assumptions and limitations explicitly, and keep the experiment single-variable.
